# odin-recipes
This project is a simple recipe website building as a practical exercise of what I learned from 
the HTML Foundation lessons by The Odin Project. 

By completing this project, I will practice and strengthen the following skills:
1. Become familiar with HTML tags and elements.
2. Learn how to initilize a basic HTML Boilerplate.
3. Learn how to work with text in HTML and use different text elements.
4. Learn how to create and use diferent types of HTML lists.
5. Learn how to work with images and links , including URLs and file paths.
6. Learn how to write clear and meaningful Git commit messages.
